Quantum Intelligence: Malware Detection with Grover’s Algorithm
🚀 Project Summary

This project demonstrates how quantum computing can enhance cybersecurity by using Grover’s Algorithm to detect malware faster than traditional methods.

Instead of scanning data linearly, this approach leverages quantum search to significantly reduce detection time for malware signatures in large datasets.

💡 What I Built
- Implemented Grover’s Algorithm from scratch using Qiskit
- Designed a system to detect:
  - Single malware hash
  - Multiple malware hashes simultaneously
- Simulated a quantum search over 4096 entries using 12 qubits
- Visualized results to confirm successful detection
⚡ Key Impact
- Achieved quadratic speedup over classical search
- Demonstrated accurate detection of malware indices with high probability
- Showed how quantum algorithms can be applied to real cybersecurity problems
🧠 Technical Highlights
- Quantum Circuit Design (Oracle + Diffuser)
- Qiskit (custom implementation)
- AerSimulator for execution
- Dataset engineering for quantum feasibility
📊 Results
- Consistent identification of correct malware entries
- Clear probability spikes in output distributions
- Successful performance in both:
  - Single-target search
  - Multi-target search
